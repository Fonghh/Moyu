# 上班摸魚（moyu）

外表是一份 Excel 報表，其實是 2D 像素釣魚遊戲。儲存格的顏色就是地形。

## 玩法
- 移動：手機拖曳畫面（虛擬搖桿）；電腦方向鍵／WASD
- 走到水邊，**按住**右下「下竿」蓄力，放開拋竿；力道越大拋越遠（電腦：按住空白鍵），蓄力時可轉向瞄準
- 按鈕一明一暗閃爍＝魚上鉤，快按「拉竿」
- 搏鬥：按住收線，張力太高或魚在掙扎時放開，收線條滿了就釣到
- 背包（按鈕上方，電腦按 I）：看釣到的魚
- 右上角小地圖：點一下放大看整張地圖（電腦按 M）
- 水裡的魚影越大，上鉤的魚越大尾
- 橘色格「釣具行」買釣竿和餌料；紫色格「魚市場」賣魚，有今日行情；四間店都在出生點周圍
- 房子按鈕（電腦按 H）：直接回城
- 粉紅格「海港餐廳」：代客料理（烤、炸、煮湯、生魚片），料理可以吃（得到加成）或賣給餐廳；門口客人有委託可接
- 金色格「遊藝場」：拉霸一次 $50，三個 7 送金條
- 釣竿等級不夠，強的魚會拉不動或直接斷線；不同魚喜歡不同餌料
- 偶爾會撈到奇怪的東西（iPhone 18、Switch 2…），可以賣高價
- **隱藏功能**：點左上角 X 圖示（或 Esc），立刻變回普通報表；切走分頁會自動切換

## 地形（儲存格顏色）
| 顏色 | 區域 | 魚種 |
|---|---|---|
| 淺藍 | 淡水・池塘 | 大肚魚、吳郭魚、鯽魚、錦鯉、黃金錦鯉、鯰魚 |
| 中藍 | 淡水・河川 | 溪哥、吳郭魚、香魚、鯰魚、櫻花鉤吻鮭 |
| 藍 | 海水・近海 | 竹莢魚、黑鯛、河豚、石斑 |
| 深藍 | 海水・深海（碼頭盡頭） | 鬼頭刀、石斑、黑鮪魚、旗魚、皇帶魚 |
| 淺綠／深綠／黃／灰／木色 | 草地／樹林（不能走）／沙灘／小徑／碼頭 | — |

- 誘餌（亮片、米諾、鐵板）：買一次一直用，魚比較快上鉤，但只有掠食魚會咬
- 船：走進水裡自動上船；一開始有舢舨（池塘、河川、近海），漁船可到深海與最東邊的遠洋
- 天氣每 3 分鐘變化（狀態列顯示）；下雨魚比較快上鉤，暴風雨時暗紅色大魚影是變種怪魚（八爪章魚、食人魚、史前巨鱷、燈籠鮟鱇王、輻射錦鯉）
